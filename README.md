# Blockbloom

An ad-free, cute block puzzle game with Classic and Adventure modes and 51 block styles.

**Play:** https://panpenk.github.io/blockbloom/

- **iPhone:** open the link in Safari, tap Share, then Add to Home Screen.
- **Android:** open it in Chrome, tap the menu, then Install app.

It works offline after the first visit. Progress saves on your device.
